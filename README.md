# GenAI User Complaint Dashboard

## Project Topic

This project analyzes negative user reviews from Generative AI apps. The main question is:

**What do users complain about in GenAI applications?**

The dashboard focuses on complaint themes, negative review trends, app-level differences, sentiment distribution, and TF-IDF complaint keywords.

## How to Run Locally

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Run the Streamlit app:

```bash
streamlit run app.py
```

If `streamlit` is not recognized, use:

```bash
python -m streamlit run app.py
```
